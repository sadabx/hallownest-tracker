# Asset attribution

The inventory and Nail upgrade icons under `public/assets/items/` are Hollow Knight game artwork sourced from the [Hollow Knight Wiki item category](https://hollowknight.fandom.com/wiki/Category:Items_(Hollow_Knight)) and its Nail article. Hollow Knight and its game artwork are © Team Cherry.

These icons are included only for identification in this unofficial, non-commercial fan tracker. They are not covered by the repository's GPL-3.0 license. The `npm run sync:icons` command documents and reproduces the source-to-local-asset import.

The interface uses the open-source Cinzel and Inter fonts through the `@fontsource` packages. Their upstream Open Font License files are included in the installed packages and production dependency metadata. Cinzel provides the Trajan-style typography without redistributing the proprietary Adobe Trajan Pro files found in the visual reference project.

The sidebar uses Font Awesome Free icons from the reference project's bundled Free webfont set. Font Awesome Free is available under the CC BY 4.0 and SIL OFL 1.1 licenses.
